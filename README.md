# Virat Kohli Tribute Page 

A simple and responsive tribute page dedicated to **Virat Kohli**, one of the greatest cricketers in the world. This project was created using HTML and CSS as part of my Web Development internship.

## 📌 Features

- Responsive design
- Clean and modern user interface
- Biography section
- Career achievements
- High-quality images
- Timeline of major milestones
- Simple navigation
- Mobile-friendly layout

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

```
Tribute-Page/
│── index.html
│── style.css
│── images/
│── README.md
```

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

Or simply download the ZIP file and run `index.html`.
